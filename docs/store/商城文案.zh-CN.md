名称：网站翻译插件

简短描述（与 manifest 一致）：使用本地词库翻译已适配的网站界面，支持按网站独立开关与持续扩展。

## 详细描述

网站翻译插件通过本地词库翻译网站界面，并支持按需生成和维护自己的词条。

- 下载词库后，在本机复用已有译文；已有词条无需每次请求 AI。
- 按主域名管理网站，单独启用、停用或排除页面路径。
- 选择目标语言，分别保存与复用不同语言的词条。
- 主动点击“添加 / 更新”或采集完成后，使用自行配置的 AI 或机器翻译接口生成词条。
- 选中页面文字，右键加入待翻译队列；加入队列不会立即调用 AI。
- 连接 GitHub 或 Gitee 词库仓库，测试令牌后选择仓库；支持确认后初始化空仓库。
- 检测远端更新、上传本地修改；冲突时先确认覆盖方向，无法可靠比较时明确询问整份覆盖。
- AI 设置、API Key、仓库令牌和网站安装清单随浏览器设置同步；未上传词条和采集队列留在当前设备。

使用前请了解：API 翻译需要你自己的服务地址、API Key 和模型设置，相关费用及数据处理由所选服务商决定。网页文字、页面路径、上下文及必要参考词条会在你发起翻译时发送到所选服务。公开词库仓库中的上传内容可被他人读取。

词库及 API Key 功能无需安装 Windows 本地程序。可选 ChatGPT 订阅模式仅供已单独安装 Windows x64 本地连接程序并具有有效授权的用户使用；目前不提供本地程序公开下载。它不代表免费提供 AI 服务或保证任意账号具有订阅接口权限。

扩展尝试保护输入框、代码和敏感数据，但不能保证识别所有敏感文本。请检查主动选取和发送的内容。首次使用及缺少词库时需要联网，已有词库可在离线时继续复用。

本项目是独立派生版本，保留上游许可证和致谢，不属于 Microsoft、OpenAI、GitHub、Gitee 或各网站的官方扩展。当前验证范围为 Windows + Microsoft Edge。
