# v0.3.4 超时设置与手动补译

本轮只更新 `edge/` 解压目录和其中的 `local-helper/`，不生成压缩包，不安装本地程序或修改注册表，不修改原 `fixed-site-translator`。

## 使用

在设置 → 常规中填写“单次请求超时（分钟）”，范围 1–60 的整数，默认 3。保存后，新任务和“重试剩余内容”使用新值，正在运行的任务保留原值。超时针对一次网络请求，包含接收完整响应的时间；不包含等待并发请求槽的时间，也不是整个多页任务的总时长。服务端、网关或网络仍可能提前结束请求。

漏译时用鼠标选中文字，右键选择“加入待翻译（网站翻译插件）”。页面会提示结果，插件弹窗显示当前网站、当前语言的待翻译数量。随后点击“添加 / 更新”，或在当前网站的多页采集结束时点击“完成并翻译”，提交对应队列。加入队列不调用 AI，也不自动开启停用的网站。

设置 → 翻译记录 → 手动待翻译显示实际保存的完整原文、网站、页面和目标语言，支持移除误选项。正在翻译的网站暂不能移除，避免与正在提交的结果竞争。失败任务中移除某项也会清除对应重试草稿，之后重试不会重新提交它。

选中部分文字时，补全为对应文本节点的完整原文；跨节点按各节点保存，不合并或替换父元素，不破坏链接及其他子元素。队列按网站、路径、上下文、原文和目标语言去重；独立于普通扫描的 500 项上限。单次选区仍限制 500 项 / 80,000 字符，本机队列限制 3,000 项 / 400,000 字符，超过时明确拒绝而不默默截断。

原文在本机持久保存，刷新或关闭页面后保留。即使更新时已经导航到同一网站的其他路径，也会处理已保存的队列；译文在对应原文再次出现时应用。切换目标语言不混用队列或译文。成功译文直接复用，不重复请求；旧 skip 记录可重新处理。服务仍返回 skip 时，任务显示未完成，原文保留待处理。

代码、输入值、可编辑区域、明确设备名或身份标记、地址、私密区和动态日志等保护继续生效，网站开关与排除路径仍生效。内置词库已覆盖的文字不覆盖。第一版仅支持主文档的普通 DOM 文本选区，不覆盖 iframe、Shadow DOM、图片文字或不可选择的属性提示。

重新加载 Edge 扩展并刷新设置页及目标网页后使用。订阅翻译还需使用本轮 `edge/local-helper/` 中的新版连接程序；若现有注册指向该目录，构建已更新文件；如果注册指向其他位置，需要按已有安装说明由用户更新并注册该副本。开发验证不会读取真实账号令牌或修改注册表。

## 实现

- `managed-batching.js` 校验分钟范围；`wt_preferences.requestTimeoutMinutes` 在本机保存。后台在每个任务启动时保存超时值，重试时刷新该值；普通 API、机器翻译和 Native Messaging 请求都接收同一值。
- `native/oauth.cjs` 把分钟换算成毫秒应用于订阅请求的完整响应周期，响应流超时分类为可重试；会话退出或取消不会当作超时重试。翻译使用 `connectNative` 持续连接，结果返回后关闭连接；后台仍保留原有有限重试策略。
- 右键菜单通过 `contextMenus.onClicked` 发起。内容脚本在隔离环境记录真实选区，校验选区、路径和原文未发生变化；后台校验网站状态和条目，串行写入 `wt_manual_queue`。网页消息不能直接启动任务或写入队列。
- 原文使用 `WTText` 的来源记录，选中已翻译文字时读取原文。`userSelected: true` 为通过共享协议校验的可选词条字段，不代表人工编写译文；人工译文仍具有原有优先级。
- `runTask` 优先合并当前网站和语言的手动输入，单独分批，绕过旧 skip；成功批次保存词条后删除相应队列 ID。未完成项目保留在队列和本机重试草稿中。删除网站后旧代次队列失效。
- 原始待翻译队列不进入 OneDrive，同步的是校验后的成功词条及用户指定标记，另一设备应用词条不触发 AI。另一设备也需更新到 v0.3.4 或更高版本以识别新增标记。

## 验证边界

回归覆盖分钟数校验与传递、手动重试读取新值、订阅流超时重试及取消、队列去重和语言隔离、旧 skip 补译、失败保留及移除、网站状态保护、部分与跨节点选区、来源恢复，以及普通扫描上限之外的手动选区。

独立 Edge 验证使用模拟网页和本机模拟 API。通过真实页面右键事件保存选区，再由隔离测试脚本调用已注册的浏览器菜单回调；不会在个人浏览器操作系统菜单上点击。验证设置回显、队列刷新保留、旧 skip 补译、页面应用和刷新复用。真实服务的模型耗时、服务端超时、订阅账号及双设备同步不属于这些模拟检查的验收范围。
