网站翻译插件

更新日志

当前版本 v0.3.0 · 翻译设置

v0.3.0 · 2026-10-30

  • 设置统一为常规、网站管理、AI 翻译、文件夹同步、翻译记录五个标签；沿用原蓝绿渐变和卡片风格。
  • 弹窗重做，保留总开关、添加 / 更新、设置，并加入开始采集、完成并翻译和取消采集。
  • 支持同一主域名内跨导航、动态弹层和由采集页打开的新窗口采集，本机累计后一次操作提交翻译；词条仍按批校验保存。
  • 网站按主域名折叠，网址卡片横向排列，分组统一启停和删除；目标语言统一移至常规设置。
  • AI 提示词可编辑并恢复默认，API 和订阅共用；补充 placeholder、aria-label、title 原文追踪与翻译，保护输入值。
  • 删除旧 GitHub 正文翻译、摘要、智能增强及设置代码，保留本地 GitHub 专用词库引擎；原有服务接口并入新翻译流程。
  • 统一 13 种服务选择与动态字段、独立本机配置；ChatGPT 订阅增加实际传递的思考强度，操作按钮优先单行。
  • 公共侧栏、按钮及输入提示跨页面去重，一次翻译多处应用；复用已存公共界面译文，不重复消耗额度。

v0.2.2 · 2026-10-30

  • 修复内置网站自行改写文本时被误判为“内置译文”、导致添加/更新漏采的问题。
  • 新增隔离世界中的文本来源交接层：内置引擎实际写入时登记原文与译文，网站后续写入使登记失效；不再从任意 DOM 变化推断翻译来源。
  • 通用内置适配器、GitHub 界面文本及选择器写入、增量词库统一保留最新原文，人工词库仍优先且不重复请求 AI。
  • 补充字符节点更新、连续改写、内置与自定义网站、停用/语言切换恢复的 DOM 与独立 Chromium 回归；保留原项目只读基线核对记录。

v0.2.1 · 2026-10-30

  • 修复订阅登录取消、端口断开、重复回调和注册交换失败的状态处理；严格验证身份及响应终结事件，保留失败前可用账号。
  • 修复跨本地进程退出与在途订阅请求的竞争；续期授权失效清除令牌，网络失败保留可重试会话，退出明确报告远端撤销结果。
  • 修复同步中文词条字节限制、对端确认校验、代次因果依赖及同一 opId 冲突处理。
  • 同步期间新修改排队重试，配置变更阻止迟到导入；导入删除先应用，确认失败不再阻止页面恢复。新修改使旧对端确认失效。
  • 新增本地回调签名测试、Native Messaging 子进程测试、登录界面失败路径及同步并发回归；真实订阅和 OneDrive 双设备步骤见 docs/订阅与同步实测清单.md。

v0.2.0 · 2026-10-30

  • 新增用户点击触发的 AI 添加/更新、批次校验、持久化进度和本地增量词库；未加载内容不计入覆盖，失败保留已保存批次。
  • 新增网站管理、具体主机权限、公共托管域名分组、人工修正、删除代次与 BCP 47 目标语言隔离。
  • API Key 模式无需本地程序；旧接口凭据迁移至本机存储。新增 Windows Native Messaging 安装脚本与官方 ChatGPT PKCE 登录、续期、流式翻译适配。
  • 新增 OneDrive 文件夹不可变变更记录、校验快照、删除标记、依赖等待及对端确认；凭据不进入同步数据。
  • 本版为开发预览：自动化测试与真实账号、三浏览器、多设备验收分开记录，详见 docs/实现与验收.md。尚未上传或公开发布。
