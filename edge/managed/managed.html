网站翻译插件

翻译设置

管理网站、选择语言，按需生成本地词库。

常规设置

所有网站使用同一目标语言。切换后复用该语言的本地词库；缺少的译文在点击添加 / 更新后生成。

可设置 1–60 分钟，默认 3 分钟。保存后用于新任务和手动重试；正在运行的任务继续使用启动时的设置。服务端可能提前结束请求。

可设置 1–120 秒，默认 12 秒。用于添加 / 更新时自动展开菜单和悬浮提示，每轮只按设置的时间限制。达到上限后，下次更新继续剩余入口。保存后从下一轮生效，正在运行的扫描保持原设置。

条数和字符数任一达到上限即停止新增；已处理项不占额度。采集上限保存后用于后续扫描，不删除当前草稿。输入预算默认 200K，范围 1–1000K，仅计算输入，不预扣输出；新任务与手动重试生效，服务和传输限制仍生效。

已添加网站

按主域名管理。展开查看网址和词库；启用、停用和删除作用于分组内已添加的网址。

下载词库

按主域名搜索当前语言词库，条件留空列出全部未完整下载的主域名。一次下载主域名及全部已发布子域名，不调用 AI。

输入条件后点击搜索，或留空查看全部未下载主域名词库。

最近任务

按文本量动态分批：输入上下文上限可在常规设置调整（默认 200K，估算，不计预计输出），全局最多 2 个请求并发。失败时保留成功结果，可重试剩余内容。

手动待翻译

选中网页文字后右键加入；点击该网站的“添加 / 更新”或“完成并翻译”时优先处理。按目标语言保存，已有译文也强制重新翻译，成功后移除；普通选区会补全为对应节点原文；邮箱前的标签仅保留标签。

任务进度

翻译服务

AI 服务设置和 API Key 随浏览器设置同步；ChatGPT 订阅登录需在每台设备分别完成。

点击翻译或连接测试会向所选服务发送待处理文字、目标语言及必要上下文；翻译任务还可能包含网址路径和参考词条。API Key 将发送给你配置的服务地址，并随浏览器设置同步。请确认服务和地址可信，避免处理含敏感信息的页面。

ChatGPT 订阅：本地连接程序

本地连接程序仅支持 Windows x64，供 ChatGPT 订阅使用。

商城扩展与本地程序分别安装。词库下载、上传、浏览器设置同步和 API Key 翻译均不需要本地程序。

暂不提供本地连接程序公开下载。只有已单独安装本地程序的用户可使用订阅功能；其他用户请选择 API 翻译服务。

下载 Windows x64 本地连接程序

已有独立安装包时，先解压，在该安装包中运行 Install.cmd，使用下方当前扩展 ID。安装会注册当前 Windows 用户的本地通信主机，不会自动登录。

首次连接会询问本地通信权限。扩展 ID 改变后需重新注册；退出登录只清除订阅会话，不影响词库和 API 设置。

翻译提示词

可调整翻译风格和内容判断，输出格式与隐私保护规则始终保留。

词库仓库

选择平台并测试令牌，可选择已有词库或空仓库。空仓库确认后自动初始化 GitHub 主站词库，已有词库直接连接。仓库选择和令牌随浏览器设置同步。

下载和检测会访问所选仓库平台；确认初始化或上传后，词条原文、译文及上下文将提交到所选仓库。公开仓库内容可被他人读取，Git 历史可能保留旧内容。
