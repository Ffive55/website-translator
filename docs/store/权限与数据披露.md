# Microsoft Edge 提交字段：权限与数据披露

适用版本：v0.3.25。发布者：Ffive55，ffive@foxmail.com。将下列说明用于 Partner Center 对应字段，最终勾选名称以控制台实际表单为准。

## Single purpose / 单一用途

按用户授权为网站界面提供翻译：下载和本机复用词库，按需调用用户选择的翻译服务生成词条，并将用户明确上传的词条同步到其选择的 GitHub/Gitee 词库仓库。

English: Translate website interfaces using local dictionaries and user-selected translation providers. Users can download dictionaries, generate translations on demand, and explicitly upload dictionary changes to their chosen GitHub or Gitee repository.

## 必需权限说明（可直接填写）

- storage：保存用户设置、网站安装清单、AI 服务配置和仓库连接信息；使用浏览器同步存储同步设置（包括用户保存的 API Key 和仓库令牌）。词库及本地修改使用 IndexedDB，不通过开发者遥测服务器上传。
- scripting：用户授权并添加新网站后，在相应页面注入扩展包内的采集、原文保护和本地译文应用脚本。不会用于加载远程 JavaScript。
- activeTab：用户在当前标签页点击扩展或发起采集、翻译时，识别并操作当前页面。不能因此读取未授权的其他页面内容。
- alarms：调度浏览器设置及词库安装清单的恢复、同步重试；不会定时发起新的 AI 翻译任务。
- contextMenus：提供“加入待翻译”右键选区入口。加入队列只保存在本机，明确发起翻译后才发送给所选服务。
- unlimitedStorage：保存已下载的大型词库、本地词条、共同基线和冲突/恢复状态，减少普通配额对离线复用的限制；并不表示向远端无限制采集或上传。

## 可选权限

- nativeMessaging（optional_permissions）：仅在用户使用 ChatGPT 订阅的本机连接、登录、模型列表、状态或退出时请求。通过 local.website_translator 与已单独安装的 Windows x64 本地程序通信。默认安装不授予此权限，词库和 API Key 模式不需要它。当前不提供本地程序公开下载，未安装的用户使用其他翻译方式。
- https://*/*、http://*/*（optional_host_permissions）：用户可添加自定义网站，并可配置自己的翻译服务地址；因此域名不能在发布时穷举。扩展只在相关操作时请求具体网站/接口来源权限，不在安装时请求所有网站。外部 API 请求只允许 HTTPS，HTTP 仅允许 localhost / 127.0.0.1 的本机服务；普通 HTTP 页面也可由用户明确授权翻译。

## 已声明主机访问

固定 host_permissions 来自当前内置适配器：GitHub 及其配置的子站、Docker 网站与工作台、Tailscale 网站与工作台，以及 api.github.com。网站权限用于对应页面词库应用，GitHub API 权限用于默认词库读取。Gitee 和其他新增网站/服务在用户操作时按具体来源请求，不会预先授权。

## Remote code / 远程代码

填写 No, I am not using remote code。所有可执行 JavaScript、处理器和允许的正则规则随扩展包发布。仓库只提供经过协议、路径、大小及 SHA-256 校验的 JSON 词库数据；数据中的处理器标识只映射包内固定实现，远程词库不能增加代码。API 返回文本先经过词条协议验证，不执行脚本，不把返回的 HTML 插入页面。词库更新不替换扩展代码。

## Data usage / 数据使用披露

该扩展会处理认证信息和网站内容，不能填写“完全不处理用户数据”。审核表单至少核对 Authentication information（API Key、仓库令牌、可选订阅授权）和 Website content（待翻译文字、上下文、译文）；站点地址与路径用于配置及翻译上下文，若表单将其归入 Web history，也需如实披露这一有限用途，不声称完全不读取网址。扩展不以浏览轨迹分析为目的采集历史。

不会为广告、信用评估、数据经纪或其他与用户可见翻译功能无关的目的销售、使用或转移这些数据。数据被发送到用户选择的翻译服务和词库平台；设置及凭据可经 Edge 浏览器同步服务跨设备传递。任务输入、队列、完整本地词库不进入设置同步。账号信息仅用于可选订阅会话。没有分析、广告或崩溃遥测 SDK。

隐私政策 URL：https://github.com/Ffive55/website-translator/blob/main/PRIVACY.md

## 需要披露的功能限制

翻译服务由用户自行配置，服务商可能收费。ChatGPT 订阅模式需要已安装的独立 Windows x64 本地连接程序及有效账号授权，当前无公开下载，不作为所有用户可直接使用的核心入口。词库和 API 模式不依赖它。非 Windows x64 设备在订阅连接时会看到不支持提示。已测平台为 Windows + Edge，不宣传未经验证的平台或账号能力。
