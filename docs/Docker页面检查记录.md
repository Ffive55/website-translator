# Docker 页面检查记录

日期：2026-10-30。按用户提供的 Docker 官网和账户工作台地址，补充官网和 Docker Hub 的本地界面词库。Docker Home 页面中的仓库入口指向独立域名 `hub.docker.com`，因此工作台适配同时覆盖该域名。

## 已检查的页面和状态

| 区域 | 核对范围 |
| --- | --- |
| Docker 官网 | 首页主要介绍、顶部和底部导航、产品入口、下载入口及价格页面的常见标签和套餐说明 |
| Docker Home | 登录后首页、产品和资源入口、账户信息、邮箱、密码提示、关联账户、隐私、停用警示、个人访问令牌列表 |
| Docker Home 账单 | 概览、发票、用量、费用、额度和账单设置；仅查看当前账户实际呈现的页面 |

| Docker Hub | 个人仓库空状态、协作仓库、默认可见性、通知设置、拉取和存储用量 |
| Docker Hub 搜索与镜像 | 镜像搜索筛选、官方 nginx 镜像概览及标签列表、拉取命令和漏洞/架构字段 |

检查过程中没有创建仓库、生成令牌、发送报告、修改账户或安全配置、提交表单、购买套餐或停用账户。账户、组织及套餐不同会显示不同功能，本记录不代表覆盖全部状态。

## 词库与保护范围

- `sites/docker/site.json`：`docker.com`、`www.docker.com`，设置页显示为“Docker 官网”。首页和价格页涵盖常见说明；其他路径优先翻译导航和操作入口。
- `sites/docker-hub/site.json`：`app.docker.com`、`hub.docker.com`，设置页显示为“Docker 工作台与 Hub”。两个适配项可分别开关。
- Docker 产品名、镜像与仓库名、标签、命名空间、摘要、地址和命令保留原文。Docker Hub 用户自写的镜像说明正文保持原文；部分通用标题会翻译。
- 用户输入、密码、代码和可编辑区域沿用通用保护。没有显式 `value` 的原生下拉选项也保留原文，以免修改表单提交值；有显式值的选项可以翻译显示文字。
- 登录验证服务 `login.docker.com`、文档站 `docs.docker.com` 和 Docker Scout 等其他独立服务不在本次注册域名内。
- 未收录的固定文案或登录后才能出现的特殊状态保持原文。Docker 改版后可按页面截图或网址继续补充词库。
