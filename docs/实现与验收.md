## ChatGPT 订阅

仅在启用订阅或同步时安装本地程序。需要 Windows、PowerShell 7、Node.js 24.15+ 及源码目录中的 npm 依赖。

```powershell
npm ci
pwsh -File .\native\install.ps1 -Browser chrome -ExtensionId <扩展详情页的32位ID>
# Edge：-Browser edge；Firefox：-Browser firefox（无需传 ID）
```

安装脚本在当前项目 `.local-native/` 生成启动器及 Native Messaging manifest，并注册当前用户 HKCU。需要保留源码位置和 node_modules；移动后需重新运行安装。升级为更新源码、npm ci、重跑安装脚本并重新加载扩展。卸载注册使用相同命令增加 `-Uninstall`，不会删除词库或登录数据。

管理页选择 ChatGPT → **Continue with ChatGPT** → 在官方授权页完成 → **读取订阅模型** → 选择模型并保存。登录期间保持管理页打开；关闭管理页会取消未完成登录。采用官方 dynamic registration、随机 state/nonce、PKCE S256、127.0.0.1 临时回调、jose 验签和 issuer/audience/exp/nonce/subject 校验。回调一次性消费；账号只在验证完成后替换。首次注册的 code 交换失败会保留待验证 client ID，下一次使用该注册重试。

令牌保存在 `%LOCALAPPDATA%\WebsiteTranslator\chatgpt.dat`，用当前 Windows 用户的 DPAPI 加密，不放入浏览器、同步目录或项目文件。请求前续期；文件锁串行化跨本地主机进程的轮换。异常中断留下 `session.lock` 时会明确拒绝并发使用，确认所有本地连接进程退出后可删除该锁再重试。当前界面管理一个注册账号；退出清除令牌并保留注册与主机身份，尚无多账号选择器。

订阅直接调用官方 `/v1/responses`，`store:false`、`stream:true`，不向模型提供工具。只在收到 completed 且 response.status=completed 的终结事件后接受译文；用量不足、失败、不完整和断流均不保存该批次。退出先更新仅本机的 `session-state.json` 会话代次标记，其他本地主机进程会取消请求并丢弃迟到结果，再尝试撤销可续期会话；失败明确提示远端撤销未确认。标记不含令牌，不进入同步目录。请求模型列表不代表该模型已通过实际推理验证。

官方依据（查阅日期 2026-10-30）：

- [Registration and sign-in](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)
- [Accounts and sessions](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)
- [Models and inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)

## OneDrive 文件夹同步

先在每台电脑确认 OneDrive 客户端同步的实际位置，并自行创建同步根目录。默认 `%USERPROFILE%\OneDrive\文档\website-translator`，可在管理页按设备修改。目录不存在直接失败，不创建一个看似 OneDrive 的替代路径。

在管理页启用同步并保存，点击“立即检查”。启动浏览器、设置变更、翻译完成时也会尝试交换。失败不会撤销本机译文。另一台设备先安装扩展/本地程序、选择同一共享目录并检查，然后授予具体网站的本机权限；应用词库不需要 AI 凭据。

- `changes/`：每设备 UUID + 单调序号的不可变记录，包含 schema、实体代次、因果依赖、操作及 SHA-256 校验。
- `snapshots/` 与 `backups/`：只包括依赖完整的记录；写入临时文件、fsync、校验后以独占硬链接发布，不能覆盖既有文件。读取也验证包含范围和依赖。备份目前为相同校验快照，无自动历史清理。
- `acks/`：完成本机持久化后写出的已应用 opId 集合。严格校验 schema、设备 ID、opId 和字段；仅发现另一设备确认涵盖本机当前已应用记录，且不存在待交换修改、坏文件或未知依赖时显示对端确认。新修改会立即使旧确认失效。传到本机目录不代表云端或对端收到。
- 幂等合并和冲突副本按 opId 去重，缺依赖记录等待；不使用设备时钟决定覆盖。独立设置字段和词条保留；删除代次压制旧离线写入，显式再添加开启新代次。
- 导出仅允许网站、开关、语言、排除路径和词条白名单。不导出 API Key、OAuth 凭据、设备私有配置、临时任务或日志。文件中的脚本字段和未知字段拒绝处理，全部作为数据读取。
- 本版单次 Native Messaging 返回限制为约 850 KB 的 UTF-8 实际字节（另有 10,000 条记录上限），达到限制明确失败，不截断词库。大词库的分页交换与历史压缩仍需后续实现。
- 同步进行中的新本机修改会安排下一轮；关闭同步/改变路径会阻止旧配置的迟到导入和确认。已写出的文件不会撤回。导入删除先通知页面，再写确认，确认失败不会阻止本机恢复原文。

SHA-256 用于完整性检查，不证明来源身份；同步内容目前未端到端加密，仅应选择自己控制的同步目录。文件系统需要支持硬链接；不支持时同步失败且不损坏已有文件。本版没有自动删除历史或删除标记。

- 覆盖统计为当前语言的增量词条数，不声称整站覆盖。按钮、导航及明确 status/tab 区域的变化数字使用受控 `{WTN0}` 占位符，本地回填当前值；不会把任意正文自动泛化为模板。已有字面占位符同样严格保留校验。
