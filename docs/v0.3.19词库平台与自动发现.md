# v0.3.19 词库平台与自动发现

日期：2026-10-31。仅更新本地 Edge 解压目录。

## 使用

1. 重新加载 Edge 扩展，打开设置的“词库仓库”标签页。
2. 选择 GitHub 或 Gitee，输入所选平台的本设备令牌。已确认过的平台可留空复用已保存或从浏览器同步恢复的令牌。
3. 点击“仓库测试”。测试分步读取授权仓库及词库索引，显示扫描进度；不创建文件、分支或提交，也不改变当前连接。
4. 在列表中选择已检测到的词库仓库，点击“确认仓库”。程序重新校验索引后保存配置和令牌，无需输入所有者、仓库或分支。
5. 到网站管理搜索下载词库，或检查已安装词库的更新。本地修改仍按主域名上传。

空仓库单独计数，不作为可连接的词库。默认分支有有效索引时优先使用，否则检查其他分支。每轮最多列出 2,000 个仓库，每个仓库最多检查 1,000 个分支列表项；达到上限时明确显示结果不完整。暂停或网络失败后可重新测试。测试会话有效期为 15 分钟；更换平台或令牌使旧候选失效。

## 实现

- dictionary-repository.js 统一配置、固定提交读取和有界响应；平台 API、鉴权头和错误提示分别处理。
- dictionary-discovery.js 分页读取用户仓库，通过 dictionaries/index.json 协议校验发现词库，不依赖名称或 README 网站清单。
- dictionary-runtime.js 保存本机候选会话，确认只接受候选 ID，不信任界面提供的新仓库参数。测试的令牌留在后台会话中，确认前不持久化；确认后的仓库和令牌随浏览器设置同步。
- GitHub 配置的规范形式沿用原 owner/repo/branch，不新增缓存键字段；旧基线、修改层、冲突候选、镜像标记与下载代次保持原身份。Gitee 配置包含 provider:gitee，与同名 GitHub 仓库隔离。
- wt_repository_credentials 按平台保存令牌，dictionaryRepository 和 dictionaryToken:github/gitee 作为白名单字段随 browser storage.sync 同步；旧 wt_repository_token 默认为 GitHub 凭据，只有所属平台才能复用。状态接口只返回是否有凭据，不返回令牌内容。
- Gitee 通过 Raw API 按完整提交下载，所有文件经过现有 SHA-256 和协议校验。上传使用一次多文件提交，三个文件保留 last_commit_id 条件；共享总索引用于检测跨分组并发修改。
- 上传前持久化事务 ID 和预期文件哈希。网络结果不明时，只读查询最近 100 个提交并校验三份文件；无法确认时保留待确认记录，阻止盲目重发。超出查询窗口需要人工核查，不自动清除状态。
- AI 服务、模型、接口地址、区域、思考强度和各服务 API Key 以受校验的 aiSettings/aiProfile 字段同步；地址和 Key 一起保存，显式清空也会同步。ChatGPT 订阅会话不复制。两端需更新至本版本以识别新增同步字段，浏览器扩展同步和相同扩展身份仍是前置条件。
- 原 GitHub 发布协议继续使用非强制分支更新；平台切换会使旧上传草稿失效，未确认的发布记录保留。

## 权限与验证边界

平台返回的 push 权限是权限提示，不代表已完成真实写入测试。GitHub 细粒度令牌需要所选仓库 Metadata 和 Contents 读取权限，上传另需 Contents 写入。Gitee 需要能访问目标仓库的令牌权限；不能直接套用 GitHub 的权限名称。

词库仓库：<https://gitee.com/Ffive/website-translator-dictionaries>。本版本已通过新实现只读发现该私有仓库，并按固定提交 45df7f52fb997cd835e603cd12a7fd289535da6f 下载、校验全部 9 个词库数据包（7,963,305 字节，含约 5.69 MB 大文件）。开发测试使用隔离 Edge 配置和模拟传输，不写真实词库仓库、不调用 AI、不安装原生程序。

本地验证结果：npm test 177 项通过；隔离 Edge 全链路 42 项通过（含两配置之间的仓库令牌和 AI Key 恢复），IndexedDB 浏览器回归 19 项通过，限流浏览器回归 9 项通过。结果记录于 .cache；真实 Gitee 并发写入、服务器 last_commit_id 拒绝行为和真实双设备同步仍需独立验收，不能由模拟测试替代。

依据：[Gitee 官方 API](https://gitee.com/api/v5/swagger)、[Gitee API 定义](https://gitee.com/api/v5/doc_json)、[GitHub 仓库列表](https://docs.github.com/en/rest/repos/repos#list-repositories-for-the-authenticated-user)。
