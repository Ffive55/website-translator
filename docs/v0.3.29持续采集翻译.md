# v0.3.29 持续采集翻译

- 按起始主域名与参与标签页限定范围；站内导航和参与页打开的同站子页面可继续，跳转到其他主域名拒绝接收。
- 常规设置新增 `translationIntervalSeconds`（1–300 秒，默认 10）与 `batchCaptureItems`（1–3000 条，默认 500），经过共享协议和设置同步白名单校验。
- 从待处理内容入队计时；空队列不请求。每批条数、输入预算或服务限制可提前触发，所有服务共用最多两个请求槽。
- 采集与请求并行；在途条目继续参与去重，跨路径公共界面保留路径，等待内容仅保存在本机。
- 结束翻译：封闭网页采集入口，处理剩余已采集内容及已访问网站的手动队列；排空前仍可取消。
- 取消翻译：中止 API 请求或断开订阅端口；保存前检查会话 ID / 状态，迟到结果不得写入；清理本次未完成任务输入，保留已保存结果。用户独立维护的右键待翻译队列不因取消会话删除。
- 已发出的远程请求不保证撤销服务端消耗。后台重启停止持续采集，显示中断，已提交批次沿用翻译记录重试；不在重启后静默继续请求。
- 保留单页扫描保护和积压条数 / 字符限制；待处理释放后广播重新扫描，采集设置在会话开始时固定。
