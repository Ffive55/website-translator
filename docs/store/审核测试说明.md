# Notes for certification / 审核测试说明

Product: 网站翻译插件 (website-translator), v0.3.25. Publisher: Ffive55. Contact: ffive@foxmail.com.

Submission record: The user submitted v0.3.25 on 2026-10-31. Partner Center shows In review, Chinese (China), Productivity and Hidden. This is not a certification approval or a public store launch.

This is an independent website-interface translation extension. It does not represent Microsoft, OpenAI, GitHub, Gitee, or the translated websites. JavaScript is included in the package. Remote repositories provide validated dictionary data only.

## 1. 安装及无需账号的核心路径

将 edge-store.zip 提交到 Partner Center；用于本地验收时可解压并从 edge://extensions 加载。ZIP 根目录有 manifest.json，没有原生可执行文件、安装脚本或本地 Node.js 运行时。

打开设置，确认版本和隐私政策入口。默认词库仓库为公开的 Ffive55/website-translator，分支 main；匿名读取无需提供个人令牌。网站管理底部留空搜索，下载 GitHub 主站或其他可用词库。打开对应网站，观察本地词库翻译；停用该网站应恢复原文，其他网站不受影响。网络或平台限流应显示错误并保留本机词库。

不得在审核截图、备注或公开 Issue 中粘贴个人真实令牌。公开仓库内容及服务可用性在提交当日需再次验证。

## 2. 词库仓库读写

有写入测试条件时，使用审核人员自己的测试 GitHub/Gitee 账号及专用测试仓库。设置选择平台，输入限权测试令牌，点击仓库测试后选择候选。此过程不应更改其他仓库。

可选择空测试仓库并确认初始化；内容只含 GitHub 主站简体中文词库、索引、许可证及来源。已有有效词库直接连接。初始化可能分步写入，取消或中断后可重试，不覆盖无关文件。

在本地编辑测试词条后上传，检查词条、清单和索引在同一普通提交中更新。制造同词条双方不同修改：点击更新应先询问采用仓库冲突项，点击上传应先询问采用本地冲突项。取消应保留数据。确认前再次修改任一端，应要求重新检测；无法可靠比较时须明确确认整份覆盖。

The publisher cannot provide access to users' private repositories. Reviewers may use an isolated repository with their own temporary token; anonymous dictionary download and local application require no private credentials.

## 3. API 翻译（无需本地程序）

在 AI 翻译选择 API 服务，配置有权使用的 HTTPS 接口、模型和测试 API Key。点击保存/测试前界面会说明数据发送与密钥同步。点击测试会发送示例文字，使用第三方服务可能产生费用。扩展不提供内置共享付费账号或服务密钥；审核人员可使用自己的测试服务，或根据需求联系发布者安排隔离测试，不应使用终端用户凭据。

在无敏感数据的页面发起添加/更新，检查待处理文字翻译、本地词条保存、输入框与代码保护。仅加入右键队列不应调用 AI；明确发起翻译才发送。保存成功词条后再次访问应复用，不重新请求。清除当前服务密钥的按钮应将该服务 key 置空，不清除其他服务配置。

Offline/credential-free core testing is described above. Actual service authorization, model availability and billing depend on the reviewer-controlled service; automated mock results are not claimed as production account acceptance.

## 4. 可选 Native Messaging

nativeMessaging is an optional permission, requested only for the subscription connection path. It is not required for dictionary management or API-based translation. The store extension does not install or run a native installer.

当前不公开提供 Windows x64 本地程序下载。因此不要把订阅登录当作所有新用户开箱可用的测试前提。已有独立安装程序的授权测试者可安装并注册当前商店扩展 ID，再由扩展检查连接、登录、读取模型和翻译。商店 ID 可能与开发版不同，需重新注册。

取消本地通信权限应显示明确提示而不影响其他功能；未安装本地程序时应提示连接不可用；非 Windows x64 平台在连接时应提示不支持。订阅登录会话保持设备独立，扩展不展示或同步其令牌。

## 5. 数据与同步

隐私政策：https://github.com/Ffive55/website-translator/blob/main/PRIVACY.md

API Keys and repository tokens intentionally participate in browser settings sync as disclosed. They are not embedded in the ZIP and are not uploaded as dictionary entries. Subscription credentials remain protected on the Windows device. Full dictionaries, capture drafts and unpublished edits are not placed in browser sync.

用独立测试配置检查站点设置同步、已上传词库恢复和本机未上传修改保留。不要用个人浏览器账户/凭据代替隔离测试。现有自动化覆盖模拟双配置恢复，不声明已经完成真实浏览器账号的双设备人工验收。
