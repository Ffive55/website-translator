# v0.3.24 商城压缩资源修复

用户上传 v0.3.23 edge-store.zip 时，Partner Center 报告包内含压缩文件。对该 ZIP 的检查发现 managed/repository-seed.json.gz：它是空仓库初始化使用的内嵌 GZIP 数据，前一版打包只检查原生程序排除，没有检查嵌套压缩资源。微软响应未给具体路径，因此修复针对已确认存在的内嵌压缩资源，不声称已通过商城线上重新校验。

v0.3.24 将该资源改为 managed/repository-seed.json，运行时直接读取 UTF-8 JSON；保持只含 github.com 主站词库、明确确认后初始化、来源与许可证及协议/SHA-256 校验。构建仅移除已知旧生成路径，保留其他工作区数据。

商城打包按扩展名及文件头拒绝 ZIP/GZIP/7z/RAR/BZIP2/XZ/Zstandard 等归档；重命名压缩文件也不能绕过。PNG 等正常资源不因此误报。最外层 edge-store.zip 仍是提交所需的 ZIP，审核资料总包内嵌商城 ZIP，仅用于交付材料，不可替代它上传。

验证包括普通种子解析、嵌套压缩回归、完整协议测试和隔离 Edge 的实际初始化流程。重新生成 v0.3.24 商城包、源码、审核材料及截图。当前隐私政策适用于数据处理方式相同的后续版本，正文和公开链接保持不变；本轮没有向商城自动提交。

2026-10-31 本轮结果：202 项自动化测试、56 项隔离后台集成检查通过；普通 JSON 种子的初始化、断点恢复及索引最后发布通过。旧包检出唯一嵌套归档 managed/repository-seed.json.gz，新商城包 45 个文件逐项检查，嵌套归档为 0，ZIP 回读、哈希及构建一致性检查通过。微软实际重新上传校验仍需在 Partner Center 验证。
