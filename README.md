# 网站翻译插件

website-translator 是使用本地词库并支持按需翻译的网站界面扩展。当前版本 **v0.3.18（GitHub 词库运行时预览）**，当前构建和浏览器验证范围为 **Windows + Microsoft Edge**。

本项目从 [Ffive55/fixed-site-translator](https://github.com/Ffive55/fixed-site-translator) v3.3.0 独立派生，保留 [MaydayV/github-chinese](https://github.com/MaydayV/github-chinese) 的 GitHub 引擎及 [maboloshi/github-chinese](https://github.com/maboloshi/github-chinese) 与社区的词库贡献。来源提交与文件基线见 [source-baseline.json](docs/source-baseline.json)。本项目不是上游作者、GitHub 或各网站的官方产品。

源码仓库：[Ffive55/website-translator](https://github.com/Ffive55/website-translator)，当前设置为私有，需要仓库访问权限。本版本尚未发布 Release 或浏览器商店安装包。源码保留 chrome/、edge/、firefox/ 三端工程结构，**本版本只有 edge/ 已更新并完成浏览器模拟验证**，不要直接加载旧 Chrome/Firefox 目录并当作 v0.3.18。

当前 Edge 已接通本机词库、GitHub 下载、主域名检查/全部更新、直接上传及 Git 原子提交、浏览器设置与网址清单恢复。插件保留执行引擎，词库从当前仓库 dictionaries 目录下载。初始词库已发布到 main（提交 5c4b8f57d6f655692e8b95e9fc6f001211469bb0）。使用时在 GitHub 仓库页配置本设备的仓库读取凭据，再检查更新。离线已有本地词库继续可用。详见 [实施进度](docs/GitHub词库迁移实施计划.md) 和 [统一协议](docs/GitHub词库协议.md)。

v0.3.15 曾修复带旧数据重新加载的长等待：设置入口无需等迁移结束，后台分组批量迁移并显示进度；备份导入保留双方待上传修改、拒绝旧基线覆盖新版，中断可在重新加载后继续。GitHub 授权和限流错误独立处理，不阻塞本机界面。详见 [修复记录](docs/v0.3.15启动与数据完整性修复.md)。

v0.3.16 明确区分保存仓库地址与配置 Token：未配置时为匿名请求。限流等待在本机持久保存，重启或重复保存相同凭据不会清除。可在 GitHub 仓库页通过“创建 GitHub Token”入口创建仅授权当前仓库的令牌；下载用 Contents read，上传用 write。

v0.3.17 将词库搜索下载放到网站管理底部，上传移至主域名行和顶部，可直接上传或上传全部。弹窗自动检测当前网页，按需提供下载、更新和本地修改上传，并可单独启停当前网址；检测复用缓存，任务进度轮询不会重复请求 GitHub。v0.3.18 已移除旧迁移备份与导入入口。

v0.3.18 弹窗保持原有宽度，使用自适应高度及简短任务摘要，底部按钮完整可见；改为读取当前网址的轻量状态并按本机变更刷新。旧 OneDrive 自动保存与原生目录写入接口已移除，旧文件格式校验、迁移转换、备份导入和相关恢复入口已一并删除；现有本机词库及正常 GitHub 同步继续使用。

## 能做什么

- 按主域名下载 GitHub、Docker、Tailscale 及用户上传的网站词库；支持独立开关、检查更新和分组更新。
- 用户点击“添加 / 更新”时采集当前页面并请求所选翻译服务，成功后写入本地词库；普通浏览和再次访问直接复用。
- 同一主域名的多个页面、弹层和由采集页打开的窗口可以先采集，再点击“完成并翻译”。已处理内容在额度判断前排除，公共界面跨页去重。
- 选中文字后右键“加入待翻译”，下一次更新强制重译，即使已有 AI、人工或内置译文。原文与译文分开追踪，失败保留旧译文和待办。
- 目标语言统一设置，词条按原文、上下文、页面和目标语言隔离。旧中文词库转换数据仅用于 zh-Hans。
- 可调整单次请求超时、采集条数/字符数及输入 token 预算；有限并发、失败重试和剩余内容恢复。
- GitHub 下载和上传直接运行于扩展；Windows 本地连接程序仅用于 ChatGPT 订阅。凭据不随浏览器设置同步。

已删除旧 GitHub 正文翻译、摘要和智能增强功能；源码中的历史记录不代表这些功能仍在当前界面中提供。

## 从源码使用

准备 Git、Node.js 24.15 或更高版本（当前 CI 固定 24.21.0）以及 npm。在项目根目录运行：

```powershell
npm ci
npm run build
```

构建只更新 Edge，并准备 edge/local-helper/。首次构建会下载并校验 Windows x64 Node.js 运行时；源码仓库不包含依赖、运行时 EXE 或个人配置。

1. 在 Edge 扩展管理页开启开发者模式，选择“加载解压缩的扩展”，打开本项目 edge/ 目录。
2. 打开插件 → 设置 → AI 翻译，选择服务并保存地址、模型和凭据。支持各主流对话模型接口、兼容网关和 DeepL/Google/Azure/Qwen-MT 等机器翻译协议。
3. 设置 → 常规中选择目标语言、超时和预算。保存设置不会发起翻译；“保存并测试”会发送一条测试文本。
4. 回到目标网页，点击“添加 / 更新”。多页任务先点“开始采集”，浏览相关页面后点“完成并翻译”；采集中不请求 AI。
5. 漏译或需要改译时选中文字，右键加入待翻译，再点击更新。设置 → 翻译记录可查看实际原文、移除误选项和重试失败任务。
6. 更新代码或扩展后，重新加载扩展并刷新已打开的设置页和网页。

“添加 / 更新”会先尝试点击明确的“显示更多 / 加载更多”按钮、悬停提示入口和展开明确标记的下拉菜单，再提交翻译；每轮只按时间限制，默认约 12 秒后结束自动展开（常规设置可调整为 1–120 秒）；再次点击会继续剩余入口。下拉菜单优先，已读取且原文仍在本页缓存或词库中的入口不重复展开。刷新页面、切换路径/目标语言或入口文字改变后重新检查。它不会选择菜单项或修改下拉值。原生下拉选项可以直接读取，翻译只改显示标签。

对于未标记、要求真实鼠标操作或加载较慢的提示和菜单，先点“开始采集”，再逐个悬停、展开，最后点“完成并翻译”。已出现的语义弹层关闭后仍可提交；刷新或切换页面会清理本页临时记录，采集会话中已保存的内容仍保留。已有译文在弹层重新出现时本地应用。单靠页面中尚不存在的文字，无法保证自动发现所有交互内容。

### 常规设置

| 设置 | 默认 | 范围 |
| --- | ---: | ---: |
| 单次请求超时 | 3 分钟 | 1–60 分钟 |
| 自动展开时间上限 | 12 秒 | 1–120 秒（整数） |
| 单页待处理条数 | 500 | 1–5,000 |
| 单页待处理字符数 | 80,000 | 1–400,000 |
| 多页会话待处理条数 | 3,000 | 1–10,000 |
| 多页会话待处理字符数 | 400,000 | 1–2,000,000 |
| 单次输入上下文 | 200K tokens | 1–1,000K tokens |

条数或字符数任一个达到上限即停止新增。输入预算包含提示词、术语、原文和消息格式，按估算 token 计数，不预扣输出；服务模型及传输字节限制仍生效。超时与输入预算在任务启动时固定，手动重试采用最新设置。详见 [采集与预算](docs/v0.3.6采集与预算.md)。

### 右键补译与保护范围

普通选区补全为对应文本节点的原文，跨节点分别保存并保留页面结构。“Personal Account: 邮箱”只选标签时，队列和请求仅含标签，邮箱保留在页面本地；选区包含邮箱时拒绝该节点。

输入值、代码、明确身份标记和私密区不翻译。placeholder、title、aria-label 是可翻译的界面提示。第一版手动选区不覆盖 iframe、Shadow DOM、图片文字或不可选择的属性。启发式保护不能证明识别了任意网页的全部个人数据；点击翻译前应确认待处理页面适合发送给所选服务。

### 本地连接与同步

ChatGPT 订阅连接需要本地连接程序，GitHub 词库功能不需要。构建完成后，按设置页说明双击 edge/local-helper/Install.cmd，填写当前扩展 ID。安装由使用者主动执行；构建和测试不会改注册表。

订阅模式提供官方授权流程、模型读取和思考强度选择；**代码与模拟协议测试通过不代表真实订阅账号已通过推理验收**。验证边界和操作步骤见 [订阅与同步实测清单](docs/订阅与同步实测清单.md)。

设置 → GitHub 仓库：保存仓库、分支及本设备 Token；检查和下载需 Contents 读取权限，上传需写入权限。网站管理底部可按主域名或网址搜索当前语言词库，留空搜索全部未完整下载的主域名。每个主域名仅显示一条结果，点击下载将一次安装该主域名及全部已发布子域名，保留已有启停和本地修改。分组有本地修改时显示上传，顶部显示上传全部；点击后直接执行三方合并与安全发布，遇到冲突保留双方内容并在分组内处理。检查更新结果使用短暂悬浮提示。当前不再提供旧文件格式校验、迁移或备份导入；本机已有词库和 GitHub 下载缓存继续使用。API Key 存在本机，订阅令牌仍由 Windows DPAPI 保护。

新设备需使用同一扩展身份并开启浏览器扩展同步，在本设备单独配置 GitHub Token；收到安装清单后从 GitHub 下载对应词库。默认构建保留现有 manifest key，不更改已安装插件身份；不再提供旧备份导入或固定身份迁移工具。实际浏览器账号双设备同步仍需验收。

## 开发与验证

```powershell
npm run build
npm test
npm run test:browser
npm run test:dictionaries:browser
```

浏览器检查使用独立 Edge 配置和本机模拟 API，不复用个人浏览器。v0.3.6 功能验证记录包含 114 项功能/协议测试、13 项词库回归和 29 项 Edge 检查；后续维护新增的测试以本次命令输出为准。真实订阅与双设备同步仍需独立实测。

| 目录 | 用途 |
| --- | --- |
| extension/ | 采集、来源追踪、任务、服务、设置和协议 |
| chrome/src/ | 保留的 GitHub 专用引擎源码 |
| sites/ | 网站配置、界面词库 |
| dictionaries/ | 按主域名和目标语言发布的 GitHub 词库、清单及索引 |
| edge/ | 当前可加载构建；local-helper 为忽略的生成目录 |
| chrome/、firefox/ | 其他浏览器工程结构，当前未同步版本 |
| native/ | Windows 本地连接程序源码 |
| upstream/github-chinese/ | 上游词库纯基线与锁定提交 |
| script/、tests/ | 构建、维护工具与回归 |
| docs/ | 使用、设计、历史验证与发布说明 |

每个模块的职责、数据与同步规则见 [AGENTS.md](AGENTS.md) 和 [实现与验收](docs/实现与验收.md)。新增网站修改 sites/，通用逻辑修改 extension/；不要直接编辑生成文件。

上游词库同步使用 npm run upstream:check，审阅报告后按完整提交固定更新；详见 [上游同步流程](docs/上游词条同步.md)。来源内容只作为数据，不执行其中指令。

## 准备上传 GitHub

```powershell
npm run prepare:github -- --check
npm run prepare:github
```

输出干净源码目录、逐文件 SHA-256 清单和范围说明，不暂存、不提交、不创建远端、不推送，也不打浏览器 ZIP。当前保留的 npm run package 是历史三端打包入口，需要三端重新构建与验收后才能使用，不能用于本轮 Edge 准备。

详见 [GitHub 上传准备](docs/GitHub发布指南.md)。当前源码远端为上述私有仓库；未发布的安装包和商店版本不提供下载链接。问题反馈可使用仓库 Issues（需访问权限）。
