## 搜索及安装说明

审核中不能从正式商城安装页获取本次提交。当前可从本仓库取得完整源码，执行 npm ci、npm run build 后在 Edge 开发者模式加载 edge/；只对当前 Edge 版本进行说明，不宣传旧 Chrome/Firefox 目录。

Hidden 是提交的实际可见性：审核通过后，用户可通过直接链接访问；不在商城搜索和分类浏览中展示。若后续希望可搜索，需要发布者在 Availability → Visibility 改为 Public，并在实际生效后更新本文。GitHub 的源码可见性与 Edge 商城 Hidden 是两个不同设置，当前 GitHub 仓库已公开。

词库搜索在扩展的“设置 → 网站管理 → 下载词库”：留空列出当前语言未完整下载的主域名，输入域名或网址筛选；成功下载后复用本机词库。切换目标语言时显示该语言内容，不跨语种复用旧译文。
