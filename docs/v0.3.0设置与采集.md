# v0.3.0 设置、服务与跨页采集

日期：2026-10-30。本次仅修改 website-translator。未操作原 fixed-site-translator 文件、个人浏览器、注册表、真实订阅令牌、OneDrive 或远端仓库。

## 界面与功能

设置统一进入 managed/managed.html；浏览器“扩展选项”和弹窗“设置”指向同一页面。原 options/options.html 只保留跳转，旧设置控件和功能代码删除。保留蓝绿渐变、白色卡片、蓝色选中标签及圆形电源开关。

五个设置标签：常规、网站管理、AI 翻译、文件夹同步、翻译记录。标签支持方向键、Home / End 和 ARIA 选中状态。桌面宽度网址卡片双列排列；主域名默认折叠，组内网址统一启停和删除。人工修正和排除路径仍属于具体网址。

本地连接程序的安装说明位于 AI 翻译标签内，只在选择 ChatGPT 订阅时显示，可按需展开；其他 API 服务完全隐藏。

弹窗只保留总开关、添加 / 更新、采集、设置；采集期间显示完成并翻译和取消采集。任务显示本地复用及跨页去重数量。所有操作通过后台可信扩展页面校验，内容脚本不能启动 AI、修改设置或操作本地程序。

## 采集与重复文本处理

- 开始采集时记录会话 ID、域名、起始标签和授权范围；内容脚本监听 DOM 变化和路由变化，保留已加载页面的原文与路径。动态登录/注册弹层属于同一页面，可采集。
- 允许从采集页打开的同主域名新标签或新窗口；不采集无关已有标签或跳到其他主域名的 OAuth 页面。主域名使用 tldts / Public Suffix List，含 private 域；本地地址保留端口分组。
- 草稿只保存在浏览器本机。收集消息经过会话、标签、origin、路径、数量和字段检查；完成时补采仍打开的页面，再封存会话并开始任务。
- 同一 origin、原文、目标语言和明确公共界面上下文跨页去重。例：/logs、/keys、/routing 的同一个 nav/span/text 的 Settings 只发送一次，结果保存到各采集路径。
- 公共 UI 已有一致译文时，未来新路径也可本地复用。精确路径的人工译文优先；有不一致人工候选时不自动跨页复用。正文仍按路径隔离，语言、上下文和站点之间不混用。
- 一次点击完成整个采集任务，但网络请求按最多 20 个去重文本分批校验。每页单次最多 500 项 / 80,000 字符，会话最多 3,000 项 / 400,000 字符；触顶明确提示。
- 会话内容不会因关闭弹窗丢失；提交后后台异常重启会将任务标为中断，已成功批次保留。尚未成功的多页内容需重新采集；当前不提供完整任务队列的断点自动重放。

## 属性来源与输入保护

text-provenance.js 增加 placeholder、aria-label、title 的实际写入记录。内置引擎与增量引擎都通过该层保存原文；网站自行更新属性立即使旧记录失效。切换语言、停用或删除时恢复最近的网站原文，不把中文译文当作新源文。

input.value、密码、textarea 的输入内容、contenteditable、代码和敏感标记不进入采集。默认提示词明确把 First name、Enter your email address、Create a password 等提示识别为 UI。iframe、封闭 Shadow DOM 与未打开页面不计入本版覆盖。

## 翻译服务合并

managed-providers.js 统一维护 13 个入口：DeepSeek、DeepL、Google Cloud Translation、Azure、Qwen-MT、OpenAI、Qwen 对话、MiniMax、Kimi、智谱 GLM、火山方舟、自定义 OpenAI 兼容接口、ChatGPT 订阅。

| 类型 | 字段与行为 |
| --- | --- |
| OpenAI 兼容对话模型 | API 地址、API Key、模型、可编辑提示词；JSON 分类及译文经过 managed-core 校验 |
| DeepL / Google / Azure | 原生翻译 API；不显示模型和通用提示词；Azure 增加区域字段 |
| Qwen-MT | 模型和 translation_options 语言参数；按单条源文调用，不把结构化分类提示当成待翻译文字 |
| ChatGPT 订阅 | 隐藏 API 地址和 Key，显示模型与思考强度；登录、读取模型、连接状态、退出按钮按需出现 |

机器翻译缺少语义分类能力，仅发送明确的界面控件及提示属性；无法判断的正文跳过。对话模型可判断长期稳定正文。机器翻译不支持的通用提示词不会展示或伪装成已生效。

每个服务独立保存本机配置；切换时恢复本服务已保存设置，当前页面内未保存的草稿也分别保留。升级在浏览器内部迁移原有服务配置，旧密钥只转入本机存储；没有读取开发者电脑上的真实账号。API Key、登录令牌、服务配置、提示词和采集草稿不进入同步数据。

“保存并测试”会真实提交一条 Save changes 并校验结果，测试可能消耗所选服务额度；普通保存不调用模型。ChatGPT 强度默认不额外发送参数；其他选择作为 Responses 的 reasoning.effort 发送，不支持的模型由服务返回失败，不静默替换强度。

## 协议依据

- [OpenAI 订阅模型与推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)：使用账号模型列表及 Responses 流式接口。
- [OpenAI reasoning.effort](https://developers.openai.com/api/docs/guides/reasoning)：强度选项与支持范围依赖具体模型。
- [DeepL 文本翻译](https://developers.deepl.com/api-reference/translate/request-translation)：text 数组和 target_lang。
- [Google Translation v2](https://docs.cloud.google.com/translate/docs/reference/rest/v2/translate) 与 [API Key 请求头](https://docs.cloud.google.com/docs/authentication/api-keys-use)：q、target、format=text；密钥使用请求头。
- [Azure Translator v3](https://learn.microsoft.com/en-us/rest/api/translator/translator/translate?view=rest-translator-v3.0)：Text 数组、to、区域认证头。
- [Qwen-MT](https://www.alibabacloud.com/help/en/model-studio/qwen-mt-api)：单条 user 消息及 translation_options。
