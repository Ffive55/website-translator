# v0.3.25 商城语言识别修复

用户上传 v0.3.24 后，Store Listings 只显示 English (United States)，没有识别简体中文。当前扩展设置界面是简体中文；旧 manifest 仅使用硬编码中文名称与描述，未声明默认语言或本地化消息文件。

根据微软发布文档的语言识别说明，补齐 default_locale: zh_CN，名称和描述分别使用 __MSG_extensionName__ / __MSG_extensionDescription__，由 _locales/zh_CN/messages.json 提供值。运行时功能、权限和隐私数据流程没有变化；目标翻译语言与界面语言是不同概念，不因为支持多种翻译目标就声明多种设置界面语言。

build-sites.js 生成 Edge 的语言资源；商城和常规打包纳入 _locales，商城校验默认语言及引用完整性。隔离 Edge 的 chrome.i18n.getMessage 验证中文名称。Partner Center 实际重新识别结果需用户替换包后确认，本地检查不能代替平台校验。

官方说明：https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension#if-a-single-locale-appears-but-the-package-includes-multiple-languages

2026-10-31：构建通过，203 项自动化测试通过；隔离 Edge 返回 defaultLocale=zh_CN，chrome.i18n.getMessage('extensionName') 为“网站翻译插件”，并生成本版 4 张截图。商城包检查包含完整语言文件、普通初始化 JSON，禁止嵌套归档。未替用户上传 Partner Center，未声明其语言识别已在线通过。
