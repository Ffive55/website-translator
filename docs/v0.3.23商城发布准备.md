# v0.3.23 Edge 商城发布准备

本轮目标是准备可审阅的商城包及资料。开发者为 Ffive55，公开联系邮箱为 ffive@foxmail.com。用户指定政策托管于 Ffive55/website-translator，并已自行将仓库改为公开；本轮仅发布 PRIVACY.md，不上传其他未提交源码。

## 产物

- edge-store.zip：根目录包含 manifest.json，仅浏览器资源、初始化数据及许可证；无 local-helper、原生 exe、安装脚本或 Node.js。
- windows-x64-helper.zip：独立订阅连接程序，包含运行时、依赖、Install.cmd、Uninstall.cmd 和使用说明；仅本地准备，不公开下载。
- source.zip：对应本地版本的白名单源码，无个人配置、依赖、缓存和 Git 历史，保留 GPL 与上游来源。
- edge-submission 目录和 ZIP：商店文案、权限/数据披露、审核测试步骤、隐私政策、截图、商店图标、商城 ZIP 和状态记录。总包不能直接作为扩展 ZIP 提交。

## 实现

script/package-edge-store.js 限定 Edge 运行资源，校验 Manifest V3、可选本地通信、引用文件、可疑凭据和原生文件排除，并回读 ZIP 逐文件比较。独立程序使用现有安装脚本，只有用户手动运行时才注册当前用户主机；程序目录需长期保留，开发不执行安装。

script/store-distribution.js 从 store/publishing.json 读取公开配置，拒绝含凭据或非 HTTPS 的发布地址。PRIVACY.md 生成扩展内 HTML 与可托管 HTML，避免双份政策漂移。公开政策校验摘要保存在忽略的 .cache/store-privacy-publication.json。

nativeMessaging 由 required 转为 optional，UI 在用户操作时请求，后台再次检查。页面显示独立程序的 Windows x64 限制及暂不公开下载；不生成虚假下载链接。不支持平台可继续使用 API/词库功能。API Key 清除按钮提交显式空值，保留其他服务配置。

script/store-screenshots.cjs 使用独立 Edge 配置、受控演示词条和模拟仓库，生成 1280×800 页面截图及 300×300 图标，不调用 AI、不使用真实账号；模拟仅用于素材和测试，不写入发布包。

## 命令与边界

运行 npm run build、npm test、npm run test:dictionaries:runtime、npm run test:browser；使用 npm run store:screenshots 生成并人工查看素材，再运行 npm run package:edge-store -- --require-ready。

公开隐私政策：https://github.com/Ffive55/website-translator/blob/main/PRIVACY.md

准备时应保留 sourceVersionPublished=false 和 certificationSubmitted=false，直至对应源码实际发布或商城实际提交。真实 API/订阅权限、真实浏览器账号跨设备同步、开发者控制台信息及最终认证需独立验证；工具不为用户提交或操作注册表。
